# Sproto Arcade

Three standalone browser games using the original character sprites and scenery from [Sproto Fighter](https://github.com/crrreatorrr/Sproto-Fighter).

Open `index.html` in a desktop browser and choose a game. Everything runs offline with the files in this repository.

| Mode | Gameplay |
| --- | --- |
| Box Barrage | Four giant bosses, ending with Bot Sales. Backpedal and dash while firing right. Press C for a tracking missile and V for a tracking bomb. |
| The Long Way Home | Side-scrolling campaign across 99 backdrops with Golden Sproto's horizontal spit. |
| Tidebreak Marina | An endless pier loop with a checkpoint each lap. |

Each game includes a `PLAY.txt` with controls. Box Barrage's projectiles and floor hazards use colored placeholders pending final attack art.
