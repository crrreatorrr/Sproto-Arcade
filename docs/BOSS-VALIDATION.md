# Boss sprite release validation

The release contains 24 boss atlases and 24 phase-specific projectile atlases. Both games use the same reviewed, source-hashed numeric geometry table (`sprite-hitboxes-v1-20261106-reviewed`). Asset decoding completes before an encounter starts; missing required renderer code fails closed when fitted geometry is enabled.

All 48 modern phase `enter`/`update` function bodies remain byte-identical to main commit `ad1e864`. Gameplay changes are confined to boss/projectile collision geometry and immutable numeric phase/weapon bindings used to select that geometry. Spawn positions, aiming anchors, movement, attack patterns, durations, damage, HP, RNG and progression remain authored. Defensive dash/shield fronts retain their full span; environment carrier debris keeps its original collision shape.

Boss body and weak-point rectangles were measured against the actual packed artwork and its exact rounded contain transform. Where necessary, vehicle drawing was calibrated around existing aiming anchors. Ordinary projectile profiles use one stable solid-core rectangle for each weapon row; source crops and common atlas bounds preserve different weapon sizes. Direction, short-ray rotation, long-beam tiling and Codebreak's local axis share the renderer's pure numeric fit helper. Thin cores are retained where the real silhouette is thin rather than enlarged into transparent space.

Before updating production replay fixtures, a paired enabled/disabled replay audit strips only `weaponPhase`/`weaponVariant` metadata and identifies the first mechanical divergence. Each level's first difference occurs on a fitted collision path (boss damage/beam impact placement or projectile contact/removal), with active geometry observed on that tick. This establishes why historical replay hashes change; it does not substitute for newly verified clear logs.

`qa/golden-disabled/` preserves the 13 original main-branch fixture files byte-for-byte. Its forced-disabled test evaluates fresh source and bundle VMs without modifying the production flag. `qa/golden/` contains legal-input production clears with god mode disabled, verified against the active geometry. Scripted clears establish deterministic completion, not human playtesting.

Required checks include both strict 48-slot asset/geometry verifiers, the repository regression runner, source/bundle replay parity, enabled and disabled collision fixtures, preload failure/retry cases, and every phase's deterministic weapon variants. The additional numeric parity diagnostic compares 960 source/bundle state hashes, exercises snapshot restoration, and observes more than 20,000 raster-core calculations. CI also runs the existing Goja and web-build/browser checks. Controlled in-level visual review is explicitly labeled and never records an earned clear.
