# Arcade contract v1

Baseline a25acb1. Offline classic scripts, global `Arcade`. Coordinates in pixels, 1280×720 viewport. Player x center, y feet; width 32, height 52. Simulation fixed 60Hz. World coordinates with camera `{x,y}` subtracted by renderer. No ES imports, fetch, external dependencies or art generation.

## Runtime packet A
Implement `runtime/core/world.js` exposing `Arcade.World` constructor `(stage,{seed=1,phase=0,sector=0,practice=false}={})`. Methods `step(input)`, `restart()`, `advancePhase()`, `lose(source)`, `clear()`, `hazard(spec)`, `target(spec)`, `platform(spec)`, `drop(id,x,y)`, `cue(text,ticks=120)`. `step` input held `{left,right,up,down}` and pressed `{jump,dash,shield,power,replace,retry}` booleans. Pressed inputs never persist. Optional weapon controller `Arcade.Weapons` instantiated by world when available, as specified below.

World fields: `stage,phaseIndex,phase,tick,phaseTick,state` (`playing|transition|lost|clear`), `player, camera, platforms,targets,hazards,shots,effects, pickups, data, events, failure, objective, progress, cueText`. Player `{x,y,prevX,prevY,vx,vy,hp,grounded,airJump,dash,dashWait,shield,shieldWait,facing}`. Floor NOT automatic: phases supply platforms. Ground speed 5, jump -13, gravity .65, double jump, ledge grace 6, dash 11 ticks at speed 22, cooldown 40. Flight speed 6, directional dash. Camera follows for `horizontal`/`vertical`; fixed for `fixed`/`flight`/`orbit`. `phase.mode` selects flight for `flight`/`orbit`, else platforming. Reset temporary collections on retry/phase, retain weapon only on phase. Transition 90 ticks then enter next phase. Baseline autofire every 12 ticks to right/facing or nearest live target for flight, damage 1; shot speed 16. Shots collide with targets via AABB, target hp reduced only when `open!==false`; dead target calls `onDefeat(world,target)` once. Stage owns completion. Invulnerability 60 ticks after hit, HP 5. Hit sources preserved. `shield` pressed lasts 45 ticks cooldown 150. Ordinary hits blocked by dash/shield; `shield` rule only countered by shield; `dash` rule only countered by active dash; `fall` bypasses both. Contact uses swept relative AABB and dedup `resolved` per hazard. Dash checked before decrement on final tick. Counter event `{type:'counter',source,rule}`. Hit event `{type:'hit',source,rule}`. Touch projectile removes hazard. Hazard TTL and cue/active schedule handled centrally.

Factories replace existing objects of same id, return object: platform `{id,x,y,w,h=20}`; target `{id,x,y,w,h,hp,maxHp,open=true,label,onDefeat}` with x/y top-left; hazard `{id,source,rule:'ordinary'|'shield'|'dash'|'fall',x,y,w,h,vx=0,vy=0,windup=0,active=1,recovery=0,age=0,resolved=false,cue}`. Hazard windup means stationary visible warning, then moves during active, removed after recovery. `hazard` does not replace an existing ID; callers use unique cycle ID. `drop` calls weapon opportunity and adds pickup; collection through overlap, occupied slot only replaced via `replace` press. Runtime invokes `stage.phases[phaseIndex].enter(world)` once and `.update(world)` each playing tick AFTER player movement and collision, so stages may inspect events; events cleared at next tick start. Optional `.draw(ctx,world)` draws custom world geometry; renderer translates camera first. No mutation of shared entries by workers.

## Stages C–F
Register with `Arcade.registerStage({id:'01-marina',number:1,title,operator,operatorSprite:'bront',color:'#...',eligibleWeapons:['prism-rail','ricochet-mine','echo-decoy'],phases:[...,...]})`.
Each phase `{name,machine,mode,objective,hudLabel,spawn:{x,y},practiceSpawn:{x,y},camera:'fixed'|'horizontal'|'vertical',enter(w),update(w),draw(ctx,w)}`. `enter` creates platforms/targets and initializes `w.data`. `w.data` resets each phase. `update` authors fixed timing with `phaseTick`, uses events, opens targets, calls `advancePhase` or `clear`. Set `w.progress` 0..1 and `w.objective` readable. Prefer no required gap until QA proves no-dash impossible. Every stage phase must require actual action, never time-only victory. Phase2 isolated introduction then compatible phase1 attack after >=600 ticks. Route objective must require reaching x/y, not timer. Use placeholder canvas machines with operator sprite supplied by root renderer at a `pilot` position optional `phase.pilot`. Supply timing and fixture notes in packet dirs. Only first slice stage initially, remaining after explicit integration gate. No final art.

## Weapons B
`Arcade.Weapons` constructor `({seed,eligible,mode,emit})`. Methods `opportunity(id,{x,y,guaranteed=false}={})` returns pickup `{id,weapon,charges,x,y}` or null; stable dedup, seeded compatible shuffle bag; `collect(pickup,replace=false)` boolean; `activate({player,targets,platforms,mode,blocked=false})` boolean; `redirect(volley)` returns volley (only `eligibleAim:true`, excluding rule dash/shield); `phase(mode)` keeps equipped charges and updates mode; `reset()` clears equipped and seen opportunities and reseeds; `snapshot()` returns `{weapon,charges}` or null. `emit(effect)` events `{type:'prism',x,y,dx,dy,damage:8,piercing:true}`, `{type:'mine',x,y,vx,vy,damage:6,radius:90,bounces:2}`, `{type:'decoy',x,y,ttl:240}`. Charges 2/2/1. Invalid activations spend none. Runtime consumes effects, handles shots/blasts, explicit aimed volleys call redirect before creation. Attack RNG `w.attackRandom` independent of weapon rng.

## QA H
Own qa/** only. Node built-ins and vm for offline scripts. Do not assume browser automation installed. Baseline entry matrix, contract fixtures and defects. Report observed separately from inferred. Deterministic simulation tests may script inputs; never report them as human playtests.

## Additive integration conventions

Approved during slice integration: `w.input` is current tick only; `w.weapons`, `w.attackRandom`, `w.redirectVolley(volley)` are exposed. Input `beam`/`bomb` drives standard recharging C/V kit. Runtime calls optional `weapons.tick(world.tick)` to expire temporary decoys. Grounded players inherit moving-platform displacement; platform authors provide `prevX`/`prevY` before moving geometry.

`stage.practiceSectors` is optional `[{id,label,phase}]`; only practice honors authored sector snapshots. Root forwards `sector` and labels records by stage, phase and sector. `phase.pilot` may be an `{x,y,scale}` feet anchor or function `(w)=>anchor`; scale is visible pixel height. `pilotHeight` is a fallback. `drawsPilot` skips root sprite drawing only when a stage actually supplies its own identity. `drawsTargetLabels` suppresses root target labels when the encounter provides readable custom labels. All are additive presentation/adapter fields, not changes to simulation semantics.

New sprite renderer crops the existing transparent PNG bounds using generated metadata in `runtime/sprite-bounds.js`; original raster files remain unchanged. Asset registration includes reference-only packs with `productionApproved:false`; registering them does not release the art gate.
